2.2-8 %如题图所示,一电容器两极板都是边长为a的正方形金属平板,两板不是严格平行,而是有一夹角$\theta$.证明：当 $\theta\ll d/a$ 时,略去边缘效应,它的电容为

%$$C=\varepsilon_0 \frac{a^2}d\Big(1-\frac{a\theta}{2d}\Big).$$



下板位于 $ z = 0 $,范围 $ 0 \le x \le a $,$ 0 \le y \le a $.

上板绕 $ x $ 轴（平行于 $ x $ 方向的一条边）旋转小角度 $ \theta $,上板平面方程：

$$z = d + y \tan\theta \approx d + y\theta$$

其中 $ d $ 是 $ y=0 $ 处的板间距.



忽略边缘效应,$ \theta $ 很小,电场线近似垂直下板,故电场大小只依赖于 $ y $

$$E(y) = \frac{U}{h(y)} = \frac{U}{d + y\theta}$$

其中 $ U $ 是两板间电压（常数）.



在下板表面（$ z=0 $）,由导体边界条件：

$$\sigma(y) = \varepsilon_0 E(y) = \frac{\varepsilon_0 U}{d + y\theta}$$



$$Q = \iint_S \sigma(y)dxdy= \int_{x=0}^{a} dx \int_{y=0}^{a} \frac{\varepsilon_0 U}{d + y\theta} dy= a \varepsilon_0 U \int_{0}^{a} \frac{dy}{d + y\theta}$$


$$Q = \frac{a \varepsilon_0 U}{\theta} \ln\left( 1 + \frac{a\theta}{d} \right),C = \frac{Q}{U} = \frac{a \varepsilon_0}{\theta} \ln\left( 1 + \frac{a\theta}{d} \right)$$


令 $ \delta = \frac{a\theta}{d} $,已知 $ \theta \ll d/a $,即 $ \delta \ll 1 $.

$$\ln(1+\delta) = \delta - \frac{\delta^2}{2} + \frac{\delta^3}{3} - \dots$$
代入：
$$C = \frac{a \varepsilon_0}{\theta} \left[ \frac{a\theta}{d} - \frac{1}{2} \left( \frac{a\theta}{d} \right)^2 + O\left( \frac{a^3\theta^3}{d^3} \right) \right]= \varepsilon_0 \frac{a^2}{d} \left[ 1 - \frac{a\theta}{2d} + O\left( \frac{a^2\theta^2}{d^2} \right) \right]$$




保留到一阶小量：

$$\boxed{C = \varepsilon_0 \frac{a^2}{d} \left( 1 - \frac{a\theta}{2d} \right)}$$

这正是题目要求证明的公式.

 $$ Q = \frac{U_X - U_Y}{\frac{1}{C_1} + \frac{1}{C_2}} $$

2.2-32 %(1)一平行板电容器两极板的面积都是$S$,相距为$d$,电容为$C=\frac{\varepsilon_0S}{d}.$当在两板上加电压$U$时,略去边缘效应,两板间电场强度为$E=\frac{U}{d}.$其中一板所带电荷量为$Q=CU$ ,故它所受的力为

%$$F=QE=CU(\frac Ud)=\frac{CU^2}{d}.$$

%这个结果对不对？为什么？

%(2) 用虚功原理证明：正确的公式应为

%$$F=\frac12\frac{Q^2}{Cd}=\frac12\frac{CU^2}d.$$

(1). 原推导错误原因

平行板电容器中，一个极板受力 = 该板电荷 × 另一板产生的电场

总电场 $ E = \frac{U}{d} $ 是两个极板电场叠加的结果。  

一个无限大带电平面单独产生的电场大小为 $ E = \frac{\sigma}{2\varepsilon_0} $。

所以受力：
$$F = Q \cdot \frac{\sigma}{2\varepsilon_0} = Q \cdot \frac{Q}{2\varepsilon_0 S}.$$

代入 $ C = \frac{\varepsilon_0 S}{d} $，得：

$$F = \frac{Q^2}{2\varepsilon_0 S} = \frac12 \cdot \frac{C U^2}{d}.$$

原推导用 $ F = QE = Q \cdot \frac{U}{d} $ 错在用了总电场。



(2) 用虚功原理证明 

考虑电容器与电压恒为 $U$ 的电源相连，忽略边缘效应。

电容 $C = \varepsilon_0 S / d$， $W_e = \frac{1}{2} C U^2$。当极板间距离 $d$ 发生虚位移 $\delta d$ 时：  

电容变化：$\delta C = -\frac{C}{d} \delta d$；  

电容器储能变化：$\delta W_e = \frac{1}{2} U^2 \delta C$；  
电源做功：$\delta W_s = U \delta Q = U^2 \delta C$；  

设外力 $F$使极板缓慢移动 $\delta d$，则外力做功 $F \delta d$。  

由能量守恒：  
$$\delta W_s + F \delta d = \delta W_e$$  
代入得：  
$$F \delta d = \frac{1}{2} U^2 \delta C - U^2 \delta C = -\frac{1}{2} U^2 \delta C.$$  
利用 $\delta C = -\frac{C}{d} \delta d$，有：  

$$F \delta d = -\frac{1}{2} U^2 \left( -\frac{C}{d} \delta d \right) = \frac{1}{2} \frac{C U^2}{d} \delta d.$$  

因此，  

$$F = \frac{1}{2} \frac{C U^2}{d}.$$  

又因 $Q = C U$，代入上式得：  

$$F = \frac{1}{2} \frac{Q^2}{C d}.$$  

证毕。
